丝路法灯 大乘取经记

建议 10–15 名学生 → 分成 4–6 组,每组 2–3 人。全班共用一块大屏幕,轮流派一位"操盘小法师"操作。

教师速览规则(30 秒版)
  1. 每队轮流经历四个回合阶段:🎲掷骰前进 → ✨机缘触发 → 🛕集市抉择 → ➜回合结束。
  2. 功德(merit)是分数;六度残页(布施/持戒/忍辱/精进/禅定/般若)是收集品,每种残页的"功德价值"不同,般若最珍贵。
  3. 集市阶段可以结缘(买/换/兑残页),也可以花功德点亮法灯"占领"一个驿站,之后别队路过都会带来双方随喜功德。
  4. 先到那烂陀寺"开悟",再返回长安才算"功德圆满"。
  5. 倒计时结束或功德库耗尽,游戏立即结算,不会拖堂;随时可点击右上角"结束游戏"提前收尾。

📜 法灯规则手册

🎯 游戏目标

全班分组扮演求法商队,沿着 🐫陆路 或 ⛵海路 前往天竺的那烂陀寺"取经开悟",再平安返回长安才算"功德圆满"。

  • 倒计时结束、功德库耗尽,或老师点击「结束游戏」,立即结算,不会拖堂。
  • 最终比较每队的总功德(手中功德 + 残页价值),排名之外,还会颁发好几项趣味称号——人人都有收获。
  • 这不是比谁最"凶",而是比谁在旅途中修得更用心、学得更多。

🔄 回合流程(像大富翁一样,一回合分四步)

每一队的回合都会经历下面四个阶段,屏幕上方的进度条会实时显示当前在哪一步:

  1. ① 🎲 掷骰前进 —— 点击「掷骰子」,商队沿骆驼🐫或商船⛵的路线前进相应的站数。
  2. ② ✨ 机缘触发 —— 落地后随机抽到一张机缘卡(善缘加分 / 小考验,都附正向引导语)、一道全班作答的智慧问答,或固定的剧情。
  3. ③ 🛕 集市抉择 —— 有站点可以选择:前往圣地结缘(买/换/兑残页)、花功德点亮法灯、或在敦煌/交趾换乘路线;也可以什么都不做,直接结束回合。
  4. ④ ➜ 回合结束 —— 点击「下一队」,轮到下一组操作。

🗺️ 地图与站点

地图上一共有四种站点,点击任意站点图标都能看到一句历史小知识:

  • 📍 普通驿站——抵达后随机触发机缘卡或智慧问答。
  • 🛕 圣地——除了机缘卡/问答,还能进行「结缘」交易,点灯花费也更高(人气更旺)。
  • ⭐ 剧情站——触发固定的历史小故事(如高昌王资助、楼兰遗梦),奖励固定。
  • 🪷 终点·那烂陀寺——陆路、海路在此汇合;第一次抵达会自动调头,踏上归途。
  • ⇄ 换乘点(敦煌 / 交趾)——每队限一次,可由陆路改海路(或反向)。

🎴 六度残页(收集品)

六度残页对应佛教"六波罗蜜",每一种的"功德价值"不同——道行越深,残页越珍贵:

买入价固定比价值高一点,所以"囤积倒卖"赚不到差价;集齐全部六种残页,译讲弘法时还有额外奖励。

🛕 集市抉择:结缘 与 点灯

结缘(仅限圣地/终点站)有三种方式,随时可切换标签:

  • 功德换法——花功德买一张残页(每种残页价格不同)。
  • 以法结缘——用自己的残页 1:1 换取想要的残页,不分价值,重在结缘。
  • 译讲弘法——把残页兑换回功德,集齐六度还有额外奖励。

点亮法灯 🪔(像大富翁"买地",但奖励是双向、正向的):

    🏆 计分与奖项

    总功德 = 手中功德 + 残页价值(集齐六度额外加分)。结束时会颁发:

    • 🏆 功德第一——总功德最高的队伍。
    • 💡 智慧奖——答对智慧问答最多的队伍。
    • 🔥 精进奖——掷骰回合数最多、最努力前进的队伍。
    • 🪔 点灯奖——点亮法灯最多的队伍。
    • 🌸 圆满奖——完成往返、回到长安的队伍。
    • 🌿 毅力奖——给予排名最后一队的鼓励称号。

    每队至少能拿到一项称号,重在参与、正向鼓励。
