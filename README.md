# 丝路法灯 · 大乘取经记

一款课堂共玩的大屏幕教学游戏。全班通过投影/电视大屏(HDMI 连接教师电脑)一起游玩,一位学生轮流担任"操盘小法师"用鼠标/键盘操作,其余同学讨论决策、共同回答"智慧问答"。游戏**不限时**:第一队(或所有队伍)回到长安时结算,出发准备里会按队伍数和旅程长度显示预计用时;一节课玩不完,下节课可以从自动存档接着玩。

灵感来自桌游《千年丝路》的核心结构(掷骰前进 → 触发事件 → 开路奖励 → 结缘交易),但主题、地图、卡牌与经济系统均为全新原创设计,围绕**大乘佛法**与真实的丝路求法史(玄奘、法显、鸠摩罗什、义净等)重新构建,财富替换为"功德"与"六度残页"的收集与运用。

## 快速开始

1. 用教室电脑(连接 HDMI 投影幕布/电视)打开 `index.html`(双击即可,任何现代浏览器,无需联网、无需安装任何软件)。
2. 按 `F11` 或点击右上角「⛶ 全屏」进入投影模式。
3. 在**主菜单**点击「🪔 开启新旅程」,按三步向导完成设置:① 组建队伍(队名、图标、颜色、陆路/海路)→ ② 旅程设置(时长、问答频率、课堂挑战、音效)→ ③ 确认出发(地图预览出发名单)。
4. 每回合:该队派代表操作「🎲 掷骰子」(或按空格),全班一起看结果、讨论决策,操盘学生可轮流更换。
5. 需要停下来讲解时按 `P` 暂停,右上角的用时也会暂停。

无需网络、无需账号、无需安装,离线即可运行。

## 🎬 三分钟讲解视频(AI 语音)

主菜单「🎬 三分钟讲解视频」或规则手册右上角「🎬 讲解视频」可以直接播放一段约 3 分钟的讲解视频:AI 中文配音 + 字幕,在真实游戏画面里逐步演示目标、分队、掷骰、机缘卡、智慧问答、课堂挑战、六度残页与行囊、结缘、点灯、换乘归途和结算。游戏中打开时用时自动暂停。

视频文件在 `media/rules-video.mp4`(也可以单独拷出来,用任何播放器或发到班级群)和 `media/rules-video.webm`。重新生成的方法见 `tools/rules-video/README.md`。

## 地图

地图是一张全部用矢量绘制的"丝路求法图",放大后依旧清晰:

- **地形**:海陆轮廓与岛屿(海南、台湾、狮子国、苏门答腊、爪哇、婆罗洲……)、天山/昆仑/葱岭/喜马拉雅等山脉、塔克拉玛干沙漠与戈壁、青藏高原、绿洲胡杨、各地森林。
- **水系**:黄河(几字弯)、长江、恒河、印度河、湄公河、塔里木河等,以及青海湖、罗布泊、热海(伊塞克湖)。
- **人文**:长城与烽燧、石窟与佛塔小画、驼队、帆船(中式硬帆船与阿拉伯三角帆船)、海上的鲸鱼海豚、罗盘玫瑰与航线、"计里画方"网格、题签与印章、玄奘誓言"宁可就西而死,岂归东而生"的竖排题跋。
- **分级显示**:默认视图只显示大地名;用滚轮、双击或右上角滑块**放大**后,会逐步出现山名、河名、湖名、小岛、航向箭头和可点击的**名胜古迹**(大雁塔、白马寺、莫高窟附近的鸣沙山月牙泉、玉门关、巴米扬大佛、菩提伽耶……)。
- **玄奘真实路线**:放大后以红色点线显示玄奘当年的去程(经热海、碎叶、撒马尔罕、巴米扬)与归程(经于阗、楼兰),可与游戏路线对照讲解。
- **地图工具**:🎯 定位当前队伍(快捷键 `F`);🗂 图层开关(地名、地貌、名胜、玄奘路线、装饰、到访足迹、网格);放大时左下角出现**鹰眼小地图**,点击或拖动可快速移动视野;棋子走出视野时镜头会自动跟随;⤢ 收起侧栏放大整体视图(快捷键 `M`)。
- 站名会自动避让,不会互相重叠;挤不下的站名会暂时隐藏(鼠标移上去或放大地图后会出现)。

## 核心玩法

每队的回合分为四个阶段,进度条会实时高亮当前所在的一步(类似大富翁的分步流程):

| 阶段 | 说明 |
|---|---|
| ① 🎲 掷骰前进 | 1–6 点,沿陆路(🐫)或海路(⛵)前进;**路过城市时可以选择进城停留**(提前停下),不会因为点数太大错过想去的城市;首次抵达新城市获得"开路功德";停在沿途村落只是歇脚,直接轮到下一队 |
| ② ✨ 机缘触发 | 落地后随机触发机缘卡(善缘加分 / 小考验,均附正向引导语)、**全班作答**的智慧问答(答对该队 +4,全班随喜 +1;选项顺序每次打乱)、**课堂互动挑战**(由老师判断是否完成),或固定剧情 |
| ③ 🛕 集市抉择 | 在"圣地"可**结缘**:功德换法(买残页)/以法结缘(残页换残页,每回合限一次)/译讲弘法(残页兑换功德,可逐张兑换,集齐六度有奖励);驿站和圣地都可以花功德**点亮法灯**;在敦煌(陆)/交趾(海)可**换乘**路线,每队限一次 |
| ④ ➜ 回合结束 | 点击「下一队」(或按 Enter),轮到下一组;所有队伍都走过一次即进入下一"轮" |
| 终点与归途 | 抵达那烂陀寺"开悟"后自动踏上归途,回到长安即"功德圆满" |
| 结束 | 不限时。按出发准备的选择:**第一队回到长安**(打完那一轮)或**所有队伍都回到长安**时结算;老师也可以随时点「结束」 |

**课堂互动挑战**:例如"说一件最近帮助别人的小事""情景小剧场""全班安静十五秒""接力说出六度"等,每张挑战对应六度中的一项;老师点「挑战成功」后该队获得功德和对应的六度残页,也可以选择跳过。可在向导第二步关闭。

**🏘️ 沿途村落**:每局开始时,在长安与第一座城、以及每两座城之间随机加入几个小村落(每局的村名和数量都不一样),让旅程更长。村落只是歇脚点:不抽卡、不答题、没有开路功德。村落多少在出发准备第二步的"旅程长度"里选:短途(不加)、标准(每段 1–2 个)、长途(每段 2–4 个,默认)。

**⏱ 不限时与预计用时**:出发准备第二步选"旅程长度"和"什么时候结算",卡片上会按队伍数显示预计用时(按每回合约 40 秒、上千局模拟估算)。5 队时大约:

| 旅程长度 | 第一队回到长安 | 所有队伍都回到长安 |
|---|---|---|
| 短途(不加村落) | 约 35 分钟 | 约 45 分钟 |
| 标准(每段 1–2 个村落) | 约 75 分钟 | 约 1 小时 40 分 |
| 长途(每段 2–4 个村落) | 约 2 小时 | 约 2 小时 30 分 |

长途适合分几节课玩完:每回合自动存档,下节课在主菜单「继续上次旅程」即可。

**🏦 功德库**:大小按旅程长度和队伍数配置,足够撑到大家回到长安。

**六度残页**(收集品,对应六波罗蜜,道行越深、价值越高):🎁布施、📿持戒、🌿忍辱、🔥精进、🧘禅定、💡般若。

**🎒 行囊**:一开始能装 4 张残页,装满后再得到的残页会直接换成功德。经过高昌(陆路)/真腊(海路)、抽到"行囊"机缘卡,或抵达那烂陀寺时,行囊扩充到 6 格,才装得下全部六种残页。

**点亮法灯 🪔**:普通驿站/圣地都可以花功德"点灯"认领(圣地更贵,每队最多 3 盏)。别的队伍之后停在你点亮法灯的站点时,双方都会获得随喜功德——正向、双赢的"驿站投资"玩法。

**评分** = 功德 + 手中残页价值(集齐六种额外加分)。结束时颁发功德第一、智慧奖、精进奖、点灯奖、互动之星、圆满奖、毅力奖等趣味称号,让每队都有正向收获。

## 存档、荣誉榜与设置

- 每回合开始时**自动存档**(顶部会短暂出现「💾 已自动保存」);已用时间每 10 秒、以及关闭/刷新页面或切到其他窗口时也会同步保存。关闭页面后(或下节课),可在主菜单「继续上次旅程」从该回合开始接着玩。暂停菜单里的「保存并回主菜单」也会保存进度;可在设置中关闭自动存档。
- 每局结束后成绩自动记入**荣誉榜**。
- 这些数据都保存在当前电脑的浏览器里(localStorage),不联网、不上传;可在设置中一键清除。
- 切换到其他窗口时游戏会自动暂停,回来时不会发现时间悄悄跑完了。

## 建议课堂流程(一节课,短途 / 第一队回到长安)

1. **导入(3–5 分钟)**:在主菜单打开「丝路百科」,介绍玄奘、法显、义净等人物和"六度"。
2. **讲解规则 + 分组(3 分钟)**:参考向导第三步的"教师速览规则",或打开规则手册。
3. **游戏进行(约 30 分钟)**:第一队回到长安后会提示"最后一轮";需要讲解时按 `P` 暂停。时间不够时老师可以随时点「结束」,或下节课接着玩。
4. **结算与讨论(3–5 分钟)**:在结算页的「问答回顾」「旅程纪事」里一起复盘,打印奖状颁发给各队。

## 自定义内容

- 新增/修改智慧问答:编辑 `js/data.js` 中的 `DR.QUESTIONS`(每题 4 个选项、正确答案下标、一句解析;游戏中会自动打乱选项顺序)。
- 新增/修改机缘卡:编辑 `DR.LAND_EVENTS` / `DR.SEA_EVENTS`;课堂挑战:编辑 `DR.CHALLENGES`。
- 调整棋盘站点:编辑 `DR.LAND_PATH` / `DR.SEA_PATH`(`x,y` 为 1080×640 地图坐标,`icon` 可覆盖默认图标,`label` 可指定站名在图标的上/下/左/右)。
- 修改百科内容、名胜古迹:编辑 `js/lore.js`。
- 调整六度残页价格、点灯规则、挑战奖励、功德库等数值:编辑 `DR.PARAMITAS` 与 `DR.CONFIG`。
- 调整队伍预设:编辑 `DR.TEAM_PRESETS`(最多 6 组);可选图标与颜色在 `DR.TEAM_ICON_CHOICES` / `DR.TEAM_COLOR_CHOICES`。
- 规则手册里的数值都是实时读取的,改完数据后无需另外修改规则文案。
