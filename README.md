# 丝路法灯 · 大乘取经记

一款面向 **9–12 岁学生**、**10–15 人**课堂共玩的大屏幕教学游戏。全班通过投影/电视大屏(HDMI 连接教师电脑)一起游玩,一位学生轮流担任"操盘小法师"用鼠标/键盘操作,其余同学讨论决策、共同回答"智慧问答"。单局约 **30 分钟**,时间到会自动收尾,不会拖堂。

灵感来自桌游《千年丝路》的核心结构(掷骰前进 → 触发事件 → 开路奖励 → 结缘交易),但主题、地图、卡牌与经济系统均为全新原创设计,围绕**大乘佛法**与真实的丝路求法史(玄奘、鸠摩罗什、义净等)重新构建,财富替换为"功德"与"六度残页"的收集与运用。

每队的回合像大富翁一样拆成清晰的四个阶段(屏幕上方有进度条实时提示):**🎲掷骰前进 → ✨机缘触发 → 🛕集市抉择 → ➜回合结束**;地图上新增了"点亮法灯"的驿站玩法,规则也整理成了一本可随时查阅的图文规则手册(菜单式说明页)。

## 快速开始

1. 用教室电脑(连接 HDMI 投影幕布/电视)打开 `index.html`(双击即可,任何现代浏览器,无需联网、无需安装任何软件)。
2. 按 `F11` 或点击右上角「⛶ 全屏」进入投影模式。
3. 在设置界面选择队伍数量(建议 10–15 人分成 **4–6 组**,每组 2–3 人)、游戏时长(默认 30 分钟)。
4. 点击「🪔 开启法路旅程」开始。
5. 每回合:该队派代表操作「🎲 掷骰子」,全班一起看结果、讨论决策,操盘学生可轮流更换。

无需网络、无需账号、无需安装,离线即可运行。

侧边栏分成「👥 队伍」「🎴 图鉴」「📜 见闻」三个标签页,不再挤在一起:队伍页显示每队的排名、功德、往返进度条与残页(点 🔍 可查看某队的完整详情,包括残页明细、点灯地点、答题与到访站点统计);图鉴页是"六度残页·功德价值"速查表;见闻页是一份实时滚动的道路见闻记录(每队的机缘、问答、结缘、点灯等事件都会记下来,方便课堂回顾"刚才发生了什么"),有新记录时标签上会出现小红点提示。

## 核心玩法

每队的回合分为四个阶段,顶部进度条会实时高亮当前所在的一步(类似大富翁的分步流程):

| 阶段 | 说明 |
|---|---|
| ① 🎲 掷骰前进 | 1–6 点,最后 5 分钟进入"冲刺阶段"自动 +1,确保按时结束;沿陆路(🐫 骆驼商队)或海路(⛵ 商船)前进,首次抵达新站点获得"开路功德" |
| ② ✨ 机缘触发 | 落地后随机触发一张机缘卡(善缘加分 / 小考验,均附正向引导语),或触发一道**全班作答**的智慧问答(答对该队 +4 功德,全班随喜 +1),或固定剧情 |
| ③ 🛕 集市抉择 | 在"圣地"站点可**结缘**:功德换法(买残页)/以法结缘(残页换残页)/译讲弘法(残页兑换功德,集齐六度有大奖);普通驿站和圣地都可以花功德**点亮法灯**(见下);在敦煌(陆)/交趾(海)可**换乘**路线,每队限一次 |
| ④ ➜ 回合结束 | 点击「下一队」,轮到下一组操作 |
| 终点与归途 | 抵达那烂陀寺"开悟"后自动踏上归途,回到长安即"功德圆满" |
| 结束 | 倒计时归零、功德库耗尽、或教师点击「结束游戏」,立即结算 |

**地图**:古地图风格绘制,飘带边框、指南针、比例尺、驼队与帆船装饰点缀其间,天空有云朵飞鸟,海面有海豚游过,驿道旁点缀着法灯灯笼,陆路(棕色)/海路(蓝色)用不同颜色的虚线标出;点击任意站点图标可查看历史小知识(圣地站点还会显示当地可结缘的六度残页种类),站点下方的小色点会记录"哪些队伍曾到访这里"。

地图右上角有一组缩放工具:拖动滑块或点击「－/＋」可将地图从 0% 放大到 100%(约 3 倍细节),鼠标滚轮悬停在地图上滚动也能缩放;放大后按住鼠标拖动地图即可平移查看细节,松开鼠标即可,不会拖出画面之外。另有「⤢」按钮(或按快捷键 `M`)可以收起侧边栏、放大整体视图,方便停下来带全班仔细看地图、讨论路线,再点一次即可缩小、恢复正常游玩布局。

**六度残页**(收集品,对应六波罗蜜,道行越深、价值越高):🎁布施、📿持戒、🌿忍辱、🔥精进、🧘禅定、💡般若——六种残页的买入价与译讲弘法价值都不相同(布施最便宜,般若最珍贵),具体数值见 `js/data.js` 的 `DR.PARAMITAS` 或游戏内规则手册的"六度残页"页。

**点亮法灯 🪔**:普通驿站/圣地都可以花功德"点灯"认领(圣地更贵,每队最多 3 盏)。别的队伍之后路过你的法灯时,双方都会获得随喜功德——是正向、双赢的"驿站投资"玩法,不会互相扣分。

**评分** = 功德 + 手中残页价值(每种残页价值不同,集齐六套额外 +10 奖励)。结束时还会颁发功德第一、智慧奖、精进奖、点灯奖、圆满奖、毅力奖等趣味称号,让每队都有正向收获。

所有数值(起始功德、行囊容量、残页买卖价格、点灯花费与随喜奖励、倒计时长度等)集中在 `js/data.js` 的 `DR.CONFIG` / `DR.PARAMITAS` 中,方便老师按班级情况微调。

## 规则手册

点击设置界面的「📜 查看完整规则」,或游戏中随时点击右上角「❓ 规则」(快捷键 `R`,`Esc` 关闭),会打开一本菜单式的图文规则手册,分标签页说明:游戏目标、回合流程、地图与站点、六度残页(含买卖价格表)、集市与点灯、计分与奖项。数值均从 `js/data.js` 实时读取,老师调整数值后规则手册会自动同步,无需手动改文案。

## 快捷键(方便讲台操作)

- `空格` / `Enter`:掷骰子 / 确认弹窗 / 进入下一队
- `1`–`4`:智慧问答中直接选择对应选项
- `R`:打开/关闭规则手册(设置界面、游戏中均可用);`Esc`:关闭规则手册
- `M`:放大 / 缩小地图(与点击地图右上角「⤢」按钮效果相同)

## 建议课堂流程(30 分钟)

1. **导入(3–5 分钟)**:简单介绍丝绸之路与佛教东传的背景,提及玄奘、鸠摩罗什等人物,说明"六度"是什么。
2. **讲解规则 + 分组(3 分钟)**:参考设置界面的"教师速览规则"。
3. **游戏进行(约 20 分钟)**:计时器自动倒数,冲刺阶段会有提示。
4. **结算与讨论(3–5 分钟)**:使用结算页自带的课堂讨论提示,回顾印象最深的智慧问答、"六度"中自己最擅长的一项等。

## 文件结构

```
index.html      页面骨架
styles.css      全部样式(大字体 / 高对比,适合投影)
js/data.js      棋盘、机缘卡、智慧问答题库、六度与队伍预设(纯数据,方便增删)
js/game.js      游戏状态与规则逻辑(不含 DOM 操作)
js/ui.js        渲染与交互(弹窗、回合流程、结算页)
js/audio.js     极简 Web Audio 音效,无需外部音频文件
js/main.js      启动绑定:计时器、快捷键、按钮事件
```

全部使用原生 HTML/CSS/JavaScript,无构建步骤、无第三方依赖,可直接以 `file://` 方式打开,也可放到任意静态服务器上使用。

## 自定义内容

- 新增/修改智慧问答:编辑 `js/data.js` 中的 `DR.QUESTIONS` 数组(每题含 4 个选项、正确答案下标、一句解析)。
- 新增/修改机缘卡:编辑 `DR.LAND_EVENTS` / `DR.SEA_EVENTS`。
- 调整棋盘站点、坐标或新增站点:编辑 `DR.LAND_PATH` / `DR.SEA_PATH`(陆路、海路目前各约 19 / 13 站 + 终点,`x,y` 为 1080×640 画布坐标,`icon` 可覆盖默认图标)。
- 调整六度残页的买卖价格:编辑 `DR.PARAMITAS` 中每一项的 `value`(译讲弘法价值)与 `buyCost`(功德换法花费)。
- 调整点灯花费、上限与随喜奖励:编辑 `DR.CONFIG` 中的 `lampCostWay` / `lampCostSite` / `lampMaxPerTeam` / `lampPassBonusOwner` / `lampPassBonusVisitor`。
- 调整功德库、集齐六度奖励等经济数值:编辑 `DR.CONFIG` 其余字段。
- 调整队伍预设名称、图标、颜色:编辑 `DR.TEAM_PRESETS`(最多 6 组)。
- 以上改动会自动同步到游戏内规则手册(数值都是实时读取,无需另外改规则文案)。
